Instalação HC

Instalar o High-Commerce

1.Executar o arquivo de instalação

No diretório escolhido (c, d, e .etc) execute o arquivo de instalação

 

Durante a execução, o processo irá realizar a extração de vários arquivos e a criação da estrutura dos diretórios necessários para o bom funcionamento do aplicativo. Após a extração dos arquivos, uma nova tela surgirá. E assim, devemos clicar no botão "Instalar".

 

 

2.Criar Estrutura

Após a instalação deve ser criado a estrutura do programa na maquina servidor.

 

 

3.Estrutura das pastas no servidor

 

:\Conttroller\dados

:\Conttroller\sistemas

:\Conttroller\servidor

:\Conttroller\relatórios

:\Conttroller\Instalar

4.Adicionar Sub-pastas

Adicionar dentro da pasta :\Conttroller as pastas

4.1. :\Backup

4.2. :\Atualização.

 

5.Conteúdo dentro das pastas:

:\Conttroller\Servidor -> FibServer.exe -> Servidor do banco

 

:\Conttroller\dados -> Nessa pasta vai estar o banco de dados com o nome GERAIS.FDB

 

:\Conttroller\sistemas -> Nessa pasta vais estar os arquivos relacionados abaixo (compartilhada):

 

1)Conttroller.exe -> Sistema gerencial High-Commerce

 

2)AutomaçãoPaf.exe - > Sistema frente de caixa do Automação Paf

 

3)PedidoSimplesPAF.exe -> Sistema de balcão do Automação Paf

 

4)Conttroller.ini -> Arquivo de Configuração do sistema de acesso ao banco

 

5)fbclient.dll ->dll do firebird essa dll caso não tenha sido marcada na instalação do firebird com a opção (Copy Firebird Client Libary to<system> directory?) a versão tem que estar igual ao do firebird instalado conferir na pasta  :\Arquivos de programas\Firebird\Firebird_2_5\bin olha em propriedades caso haja .

 

6)FBConttroller.dll > dll é copiada na pasta C:\Program Files\Firebird\Firebird_2_5\UDF para nova versão Firebird-2.5.exe
