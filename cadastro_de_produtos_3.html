Cadastro de Produtos

Identificação do Item

 

1.Código do Produto = 60 caracteres máximo

2.Nome = 120 caracteres máximo

3.Tipo = definir conforme;

3.1. -Produtos = Todos os itens que movimentar o estoque de algum modo

3.2. -Serviço = Todos os itens que for calcular ISS

3.3. -Outros = Todos os itens que Não movimentar estoque mais tem que ser informado no livro fiscal (SPED)

4.Código de Barras - informar o GTIN (Global Trade Item Number) do produto, antigo código EAN ou código de barras. Preencher com o código GTIN-8, GTIN-12, GTIN-13 ou GTIN-14 (antigos códigos EAN, UPC e DUN-14), não informar o conteúdo da TAG em caso de o produto não possuir este código.

5.Tributação

5.1.Situação Tributaria

5.1.1.Saída = Informar conforme regime do produto para saída

5.1.2.Entrada = Informar conforme regime do produto para Entrada

6. Alíquotas (%)

6.1.ICMS/ISS Saída = Informar o valor da alíquota de saída dentro do estado (BA)

6.2.MVA = Informa a alíquota para os produtos com Situação tributaria 2º e 3º dígitos EX.: 10,30,60,70

6.3.IPI Entrada =

6.4.IPI SAIDA

7.Outros

7.1.Redução Substi. = Informa valor de redução para produtos Situação tributaria 2º e 3º dígitos Ex.: 70

7.2.Redução Entrada = Informa valor de redução para produtos Situação tributaria 2º e 3º dígitos Ex.: 20 ou 70

7.3.Redução Saída = Informa valor de redução para produtos Situação tributaria 2º e 3º dígitos Ex.: 20 ou 70

8.CFOP = Informar o CÓDIGO FISCAL DE OPERAÇÕES E PRESTAÇÕES conforme a operação e/ou Situação tributaria do produto
