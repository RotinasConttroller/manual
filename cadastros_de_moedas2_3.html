Cadastros de Moedas ECF

 


Atenção para Código interno das Moedas. As base novas já vem com estas moedas cadastradas, porém as antigas devamos sempre verificar. Caso as moedas Dinheiro e Cheque não tenham os código internos como no exemplo, a base deve ser enviada para Programação analisar. Exemplo:

Dinheiro deve ser código 1

Cheque deve ser código 2
