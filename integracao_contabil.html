Integração Contabil

▪Manual Exportação para Sistema Contábil

▪Pré-requisitos:

➢Caso a contabilidade da empresa só adquirir o sistema contábil depois de a empresa adquirir o HC a contabilidade não  pode iniciar o plano de Contas deve ser configurado primeiro no HC

➢Caso contrario importar o plano contábil da contabilidade para HC. Ver com programação programa de importação Contábil x High

➢Configura a estação com Zeos Local. Com Zeos local a rotina fica mais rápida.

➢Evitar executar rotina no servidor.

 

▪Configurações e Parâmetros

❖Cadastros>> Classificação de Títulos.

♦Serve como plano de contas gerencial. Já vêm cadastros os códigos de 0 a 9. Estes NÃO podem ser deletados.  O Código = 0 pode ficar inativo, já os demais NÃO podem.

➢Código= será informado automaticamente

➢Nome = Usuário pode dar o nome que desejar. EX.:

➢Nome da empresa= caso empresa trabalhe com mais de um estabelecimento e a classificação for ser usada por todos manter este campo = “ EMPRESA CONTTROLLER”

➢Tipo = Ira influenciar não só na exportação como nos relatórios financeiros

▪RECEITA = Para todos os títulos que represente as receitas do estabelecimento: EX.:

●Vendas a vista

●Vendas a prazo

▪DESPESA =Para todos os títulos que represente as despesas do estabelecimento: EX.:

●Compras a prazo

●Compras a vista

▪OUTROS = Para títulos em geral

▪MULTA = Será utilizada para os valores de multa tanto para credito quando débitos

▪JUROS = Serão utilizados para os valores de juros tanto para credito quando débitos

▪BANCO = Usado para lançamentos de transferência Ex.:

●Banco para Banco

●Caixa para Banco

●Banco para Caixa

 

 

 

 

 

 

 

 

 

 

 

❖Cadastro de Cartão de Credito

●Localize no plano de contas nome das contas para “Cartões de Créditos”:

●Informe no cadastro do cartão a que conta contábil será informada seus lançamentos. Mesmo que o estabelecimento tenha vários cartões cadastro é Contabilidade que ira informar para que Conta contábil será exportado os lançamentos.

 

 

 

 

❖Cadastro da Conta Corrente

●“000” ou Fundo de Caixa. Deve ter o banco “0” e pode ter o numero que cliente quiser.

 

❖Cadastro Conta Plano de Contas:        

▪Clique em “Atualizar Dados” (F5) para visualizar todo plano de contas

▪Clique em “Expandir Tudo” (F7) para expandir o plano

 

▪Após a Atualizar localize no plano de contas a conta de grau 4  “ Banco conta Movimento” e cadastre as contas correntes conforma modelo no grau 5

●Nome do banco seguido de “-“ e numero da conta

 

▪Localize no plano de contas  as conta “Duplicatas a Receber “e “Fornecedores”  no Grau 4 e associado a seu código reduzido antes de começar a gerar arquivo, ao nome de cada cliente/fornecedor.

▪Use F6 para trocar o campo de pesquisa para:

●CNPJ;

●CPF;

●Código;

●Nome;

 

❖Cadastro>> Classificação Contábil

 

●Selecionar a classificação de títulos Ex.:  Vendas A Vista ou A prazo

♦Clicar em Incluir = Para configurar a classificação conforme Plano Contábil

➢Tipo =

▪Banco = Para Lançamentos Contábeis com Operação Debito na contas correntes

▪Caixa = Para lançamentos Contábeis com Operação de Debito na conta 00000

▪Acréscimos = Para Valores de Acréscimo no título

▪Descontos = Para Valores de Descontos no titulo

▪Principal = Representa a conta principal no Plano de contas Contábil

▪Outros = Se comportam como Principal podendo ser usado por Ex.: Tarifas bancarias, Tx Adm

▪Cartão = Para Títulos de Cartão de Credito

▪Juros = Para  Valores de Juros no titulo

▪Multa = para valores de multa no Titulo

➢Operação =

▪Debito

▪Credito

➢Plano de Contas Grau 4 = Deve ser informado a conta da contábil, Não pode ficar em Branco

➢Plano de contas Grau 5 = Deve ser Informado a Conta Contábil, podendo ficar em Branco quando tiver varias opções.

▪Ex. Grau 4 -“Duplicadas a Receber”  pode ter vários Clientes logo deve ficar com grau 5 em branco. Já “Descontos e Abatimentos” devem ter seu grau 5 preenchido. Ex. Venda a prazo com Cartão de Credito

➢Histórico = Informar os dados do titulo para identificar no sistema Contábil. Devem ser informados sempre os campos de maior importância, pois só são importados  100 caracteres. Clique com Botão direto do mouse para listar o campos. No primeiro exemplo a referencia e código do titulo serão cortados caso o Nota fiscal e Nome do cliente tenha mais de 100 caracteres. Para não ter estes dados cortado selecionar os campos mais importantes primeiro Ex. abaixo:

▪RECEBIMENTO REF. NF.NOTA FISCAL: <Nota Fiscal> DUPL DE: <ClienteFornecedor>  N.REFERÊNCIA: <N.Referência> CÓDIGO: <Código>

▪RECEBIMENTO REF. CÓDIGO: <Código> N.REFERÊNCIA: <N.Referência> NF.NOTA FISCAL: <Nota Fiscal> DUPL DE: <ClienteFornecedor>
