Complementar Preenchimento

1.Dados do Destinatário/Remetente

1.1.Deverá constar como destinatário, o nome, o endereço e os números de inscrição estadual e no Cadastro Nacional de Pessoa Jurídica (CNPJ) do contribuinte ao qual foi impressa a NFe que está sendo complementada.

 

2.Natureza da operação (Tipo)

2.1.Pode ser Complemento de ICMS / Complemento de Valor ...

2.2.Ou conforme orientação do Fisco

 

3.Dados do Imposto

3.1.Apenas deverão ser informados, os campos a serem complementados,

 

4.Dados do Produto

4.1.- Código do Produto = cadastrar novo produto do TIPO = Outros com o nome do complemento do impostos.

4.2.- CFOP = utilizar o mesmo código da nota emitida com erro.

4.3.- Quantidade = 1 (um) ou a quantidade a ajustar

4.4.- Valor Unitário = 0  (zero) ou valor a ajustar, habilitar parâmetro de usuário para permitir o valor zerado

4.5.- Código de Situação Tributária = utilizar o mesmo código da nota emitida com erro. (Fig. 1)

4.6.- Código do NCM = utilizar o  mesmo código da nota emitida com erro ou 00 (zero) caso seja complemento de ICMS

4.7.Código do SPED =  99 - Outras

 

 

5.- Modalidade de determinação da Base de cálculo = 'Valor da operação'.

5.1.- BC ICMS = Valor do ICMS a complementar, referente ao item ou 0 (zero) caso não seja complemento de ICMS

5.2.- Alíquota ICMS = 000. Obs.: campo será preenchido somente para permitir a validação da NF-e; ou 0 (zero) caso não seja complemento de ICMS

5.3.- Valor do ICMS = Valor do ICMS a complementar, referente ao item; ou 0 (zero) caso não seja complemento de ICMS

5.4.- BC ICMS ST = Valor do ICMS ST a complementar, referente ao item ou 0 (zero) caso não seja complemento de ICMS ST

5.5.- Alíquota ICMS ST= 000. Obs.: campo será preenchido somente para permitir a validação da NF-e; ou 0 (zero) caso não seja complemento de ICMS ST

5.6.- Valor do ICMS ST = Valor do ICMS ST a complementar, referente ao item; ou 0 (zero) caso não seja complemento de ICMS ST

 

6.Cálculo do Imposto.

6.1.- Base de Cálculo ICMS = Valor do ICMS a complementar ou 0 (zero) caso não seja complemento de ICMS

6.2.- Valor do ICMS = Valor do ICMS a complementar ou 0 (zero) caso não seja complemento de ICMS

6.3.- Base de Cálculo ICMS ST = Valor do ICMS ST a complementar ou 0 (zero) caso não seja complemento de ICMS ST

6.4.- Valor do ICMS ST = Valor do ICMS ST a complementar ou 0 (zero) caso não seja complemento de ICMS ST

6.5.- Valor Total dos Produtos = Valor dos produtos, caso seja complemento de valor ou 0 (zero) caso seja outro tipo de complemento

6.6.- Valor total da Nota Fiscal = Valor dos produtos, caso seja complemento de valor; ou Valor do ICMS ST, caso exista complemento de ST; ou 0 (zero) caso seja outro tipo de complemento;

 

 

7.Dados do Transportador

7.1.A modalidade de frete deve ser informada como frete por conta do emitente = 0. Os dados da transportadora são dispensados.

 

8.Dados Adicionais / Informações Complementares

8.1.Preencher conforme o regulamento. Podem ainda ser inseridas observações de interesse do contribuinte, além da descrição dos documentos fiscais referenciados
