IBExpert

Instalar o IB-Expert.

Criar uma conexão com o D:\CONTTROLLER\Notaeletronica\banco\NFELETRONICA.FDB.

* Abrir o banco para testar conexão

 

 

1 – Atualizar e configurar High-Commerce

1.– Realizar backup da Base de Dados;

2.– Atualizar High-Commerce com a versão mínima de data 11/02/2011 para empresa com regime NORMAL e 15/03/2011 para SIMPLES NACIONAL;

3.– Acessar o Banco pelo IBExpert;

4.– Acessar a tabela ESTABELECIMENTO;

5.– Anotar os “INTERNO_ESTABELECIMENTO” dos Estabelecimentos que emitem Nota Eletrônica;

6.– Acessar a tabela PARÂMETRO_INTERNO;

6.1– Inserir uma linha clicando no na figura  ;

6.2– Preencher a linha com as seguintes informações:

6.2.1– Interno Seqüencial da tabela

6.2.2– Interno Estabelecimento (Obs: Se houver mais de um estabelecimento emissor de NF-e, criar uma linha para cada estabelecimento.)

6.2.3– Nome da Rotina, no caso NFE2G

6.2.4– Valor: S. (Obs: Utilizar o Padrão “S” e não, “Sim” como nos outros.)
