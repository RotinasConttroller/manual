Barras de Ferramentas

Barra de ferramentas de banco de dados

Esta barra de ferramentas padrão pode ser visto na principal IBExpert janela. Ele pode ser misturado dentro e fora usando o IBExpert menu Exibir / Barra de ferramentas(caixas).

Os ícones (da esquerda para a direita) pode ser usado para executar as operações seguintes:

1.Registre-se Banco de Dados [Shift + Alt + R]

2.Cancelar o registro de banco de dados [Shift + Alt + U]

3.Ligação à base de dados [Shift + Ctrl + C]

4.Desconectar do banco de dados [Shift + Ctrl + D]

5.Volte a ligar à base de dados

6.Criar banco de dados

7.Sair [Alt + F4]

Estes itens também podem ser encontradas no principal menu Base de dados IBExpert . Para alterar, personalizar ou redefinir esta barra de ferramentas, consulte Barras de ferramentas .

 

 

Barra de ferramentas Editar

Esta barra de ferramentas padrão pode ser visto na principal IBExpert janela. Ele pode ser misturado dentro e fora usando oIBExpert Ver Menu / Toolbar (caixas).

Os ícones (da esquerda para a direita) pode ser usado para executar as operações seguintes:

1.Carregar do arquivo [Ctrl + L]. A seta para baixo produz uma lista drop-down dos arquivos mais recentes.

2.Salvar em arquivo [Ctrl + S]. A seta para baixo produz uma lista drop-down dos arquivos mais recentes.

3.Corte [Ctrl + X]

4.Copiar [Ctrl + C]

5.Cole [Ctrl + V]

6.Encontre [Ctrl + F]

7.Pesquisar novamente [F3]

8.Substitua [Ctrl + R]

Estes itens também podem ser encontrados nos principais menus IBExpert Editar . Para personalizar ou redefinir esta barra de ferramentas, consulte Barras de ferramentas .

 

 

Barra de Ferramentas

Esta barra de ferramentas padrão pode ser visto na principal IBExpert janela. Ele pode ser misturado dentro e fora usando oIBExpert Ver Menu / Toolbar (caixas).

Os ícones (da esquerda para a direita) pode ser usado para executar as operações seguintes:

1.Editor SQL [F12]

2.Novo Editor SQL [Shift + F12]

3.Query Builder

4.Script Executive [Ctrl + F12]

5.SQL Monitor de [Ctrl + M]

6.Pesquisar em Metadados [Shift + Alt + F]

7.Extrair Metadata

8.Imprimir Metadados

9.User Manager

10.Grant Manager

11.Gerenciador de Relatórios

12.Blob Viewer / editor

Estes artigos também podem ser encontrados na página IBExpert Ferramentas de menu . Para personalizar ou redefinir esta barra de ferramentas, consulte Barras de ferramentas .

 

 

Novas barra de ferramentas Objetos de banco

Esta barra de ferramentas padrão pode ser visto na principal IBExpert janela. Ele pode ser misturado dentro e fora usando o IBExpert Ver Menu / Toolbar (caixas).

Os ícones (da esquerda para a direita) pode ser usado para executar as operações seguintes:

1.Novo Domínio

2.Nova Tabela

3.Nova Visão

4.Novo procedimento

5.Novo Gatilho

6.Novo Gerador

7.New Exception

8.New UDF

9.Novo Papel

Estes itens também podem ser encontradas no principal menu Base de dados IBExpert ou no IBExpert DB Explorador , clicando no botão direito do rato para oferecer uma opção de contexto para o objeto de banco de dados selecionado. Alternativamente [Ctrl + N] pode ser usado na DB Explorer para criar novos objetos (fornecendo um tipo de objeto tenha sido selecionado).

Para personalizar ou redefinir esta barra de ferramentas, consulte Barras de ferramentas .
