Codigo de Barras Lote/Grade

Configuração para código barra

1-Produtos sem grade:

a.Rotina – Especiais > Geração de código Barras:

b.Parâmetros de estabelecimento > Padrão Código barras = EAN13

c.Sistema vai gerar os códigos sempre iniciados por (9), pois é o padrão do EAN13.

 

2-Produtos com grade ou sub-grade:

a.Rotina – Especiais > Geração de código Barras:

b.Parâmetros de estabelecimento > Padrão Código barras = EAN13

c.Parâmetros de estabelecimento > Composição código barras da grade = automático:

i.Código 1 = Produto; TAM = 5

ii.Código 2 = Grade; TAM = 4

iii.Código 3 = Cor; TAM = 3

iv.Inicio = pode ser iniciado por qualquer numero deste que não seja (9) que será usado no código de barras do produto sem grade;

v.Máscara = 99999-9999-999 ou 99999/9999/999 ou 99999.9999.999

3-Lembrar sempre de:

a.Nunca alterar os parâmetros e gerar novos códigos se já tiver etiquetas impressas. Sempre que se rota rotina geração de código de barras o sistema gera novos números para grade se as etiquetas já foram impressas causa erro!!!

b.Sistema só gera códigos automáticos para grade/subgrade para produto só com a rotina geração de códigos
