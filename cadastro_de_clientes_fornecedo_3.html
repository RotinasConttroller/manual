Cadastro de Clientes/Fornecedor

Campos Obrigatórios

 

Pessoa = Jurídica

1.Nome = Razão social do cliente, evitar caracteres acentuado e &

 

2.Dados Principais:(Fig 1)

2.1. CNPJ =  Informar conforme registro do cliente no SEFAZ ou para as notas de importação informar o CNPJ do emitente

2.2. Inscrição Estadual =  Informar conforme registro do cliente no SEFAZ ou para as notas de importação informar o I.E. do emitente

2.3. Regime Tributário = Informar conforme registro do cliente no SEFAZ

2.4. Objetivo ICMS = Informar conforme registro do cliente no SEFAZ

2.5. Endereço Principal:

2.5.1. Endereço = logradouro

2.5.2. Complemento = complemento do endereço, o conteúdo pode ser omitido

2.5.3. Numero =  informar S/N quando inexistente para evitar erro de Schema XML

2.5.4. UF = sigla da UF conforme registro da Inscrição Estadual ou para notas de importação a UF = EX

2.5.5. Município =  Conforme registro da Inscrição Estadual ou para notas de importação o nome do PAIS, código do município, deve ser compatível com a UF será informado conforme tabela do IBGE, nas operações para exterior será 999999

2.5.6. CEP = Conforme registro da Inscrição Estadual , CEP deve ser  sem máscara

3.Cobrança, SPC e Outros

3.1.E-mail = informar o e-mail do destinatário, pode ser omitido, SEFAZ permiti no mínimo 60 caracteres (Fig.2)
