Parametros Usuarios

 


Em parâmetros usuários são configurados todos os direitos e restrições de acesso de cada pessoa que vai usar o sistema Automação.

O menu de acesso às opções do sistema é montado de acordo com a função de cada pessoa na empresa.

Parametro Usuarios PAF

 



Associar =  Permissão ao usuário para utilizar os Tipos de entradas/saídas

 

 

 


A maioria dos parâmetros tratados neste item servirão como padrão na inclusão dos caixas.

Nos itens seguintes descrevemos cada um dos parâmetros.

§

Pedir nome do vendedor? Esta opção só tem sentido se a loja possuir controle das vendas para calcular comissão para vendedores. Se responder "S" o sistema calcula a comissão da venda nas notas geradas, usando as definições da tabela de preços e comissões. Caso tenha respondido "N" , informe nome do vendedor que deseja que seja assumido nas vendas no parâmetro de estabelecimento.

§

Pedir nome cliente? Esta opção só tem sentido se a loja desejar possuir os registros das vendas individualizadas por cliente. Normalmente, numa loja com automação, não possui este tipo de registro, pois geraria uma demora maior da operação de vendas no caixa.Neste caso informe no parâmetro de estabelecimento o "CONSUMIDOR FINAL" que por default tem código "0". Se respondeu "S" à pergunta anterior  deixe o parâmetro em branco e habilite no parâmetro de estação a opção "Solicitar ao iniciar uma venda" uma das opções da lista.

 

 

§

Acessar cadastro de Cheques. Informe se deve visualizar a tela cadastro de cheque no momento das venda.

§

Permitir realizar sangria? Sangria é o nome dado à retirada de dinheiro do caixa e transferência para o caixa central. Neste campo deve ser informado se é permitido ou não. Se responder "S" o sistema o sistema permiti ao usuário realizar a sangria. Caso tenha respondido "N" será solicitado a senha do Supervisor. O limite da sangria depende do valor disponível no caixa.

§

Permitir realizar suprimento? Suprimento esta operação é o inverso da sangria, registra a entrada de recursos no caixa. Geralmente é usada para incrementar o fundo de troco.Neste campo deve ser informado se é permitido ou não. Se responder "S" o sistema o sistema permiti ao usuário realizar o Suprimento. Caso tenha respondido "N" será solicitado a senha do Supervisor.

§

Permitir realizar troca? Fiscalmente Não existe o documento TROCA o que existe é DEVOLUÇÃO. A opção troca é apenas para que o caixa possa vincular a mercadoria recebida como moeda de pagamento. Se responder "S" o sistema o sistema permiti ao usuário realizar a troca. Caso tenha respondido "N" será solicitado a senha do Supervisor

 

§

Permitir alterar o preço unitário? Normalmente, não é permitido a alteração de preços durante a operação de vendas num processo de automação comercial, no entanto se este for o seu caso deve ser usado a tela de pedido simplificado para se lançar o pedido e finalizar no Automação.

§

Utilizar tabela de preços. Informe qual tabela de preços que deseja utilizar nas vendas.

§

Permitir desconto sobre um produto? Caso a sua loja tenha uma política de descontos diferentes por produto, embora esta opção não é muito prática numa operação de vendas num caixa automático. Se este for o seu caso deve ser usado a tela de pedido simplificado para se lançar o pedido e finalizar no Automação.

§

Permitir desconto sobre o total? Ao informar a formar de pagamento usuário pode selecionar o desconto "F8" para descontos em R$ ou "F7" para descontos em % , faz com que o sistema abra um campo pedindo o valor do desconto no momento do fechamento da venda.

§

Validar Situação Financeira do Cliente. Bloqueia clientes com títulos vencidos. Se responder "Sim" o sistema bloqueia todos clientes com títulos vencidos e em aberto.Se responder "Não" cliente está liberado. Se "Parcial" mesmo comportamento de "Sim", mas não critica Pedido, Orçamento, Pré-Nota.

§

Verificar Limite de Credito. Bloqueia clientes com limite de vendas. Se responder "Sim" o sistema critica todos clientes com limite de credito.Se responder "Não" cliente está liberado. Se "Parcial" mesmo comportamento de "Sim", mas não critica Pedido, Orçamento, Pré-Nota.
