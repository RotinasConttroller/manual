Instalando ConttrollerSincZEOS (Cliente) 

* LOJA

  > Sinronizador = contendo a pasta FTP_Files, Contsinc e Contsinc.conf, (arquivo de configuração do Contsinc), FTPClient e FTPClient.conf (arquivo de configuração do FTPClient);

  > FTP_Files = armazenará as pastas CAD (cadastro) e MOV (movimento);

  > CAD = pasta que armazenará os arquivos de cadastro recebidos do servidor, irá conter a pasta PROC;

  > PROC = ira possuir subpastas com data onde estarão sendo armazenadas os cadastros PROCESSADOS por data de sincronização;

  > MOV = pasta que armazenará temporáriamente os arquivos de MOVIMENTAÇÃO para serem enviados para o servidor

 

 

b)

Configurando  o ConttrollerSincZEOS (Cliente)

i)

Local Banco : Informar caminho para Banco local

ii)

Porta Master = 9050

iii)

IP servidor Zeos = Informar IP do servidor;

iv)

Porta FIREBIRD = 3050

v)

(2)

Informar SENHA = sinccont

Confirmar o  Numero do estabelecimento

Confirmar instalação do estabelecimento

(5)
